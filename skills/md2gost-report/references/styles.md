# Значения оформления и правила

Читай этот файл только при требованиях к оформлению в задании или прямом обращении пользователя к стилям. Это справочник, а не блок настроек для копирования в отчёт.

Сопоставь требование со значением по умолчанию. Добавляй только правила, которые действительно меняют результат. Сохраняй уже согласованные настройки существующего отчёта. Не добавляй автоматически готовый набор стилей или шрифты из другого образца.

Правила действуют на весь документ. При повторном задании параметра используется последнее значение. Размер шрифта и интервалы задаются в пунктах, абзацный отступ — в сантиметрах, межстрочный интервал — множителем. Название шрифта с пробелами записывается без кавычек.

## Основной текст

| Параметр | По умолчанию | Изменение при необходимости |
|---|---|---|
| Шрифт | Times New Roman | `!!rule text font <название>` |
| Размер | 14 пт | `!!rule text size <целое>` |
| Межстрочный интервал | 1.5 | `!!rule text line_spacing <число>` |
| Абзацный отступ | 1.25 см | `!!rule text indent <число>` |
| Интервал после абзаца | 0 пт | `!!rule text spacing after <целое>` |
| Выравнивание | По ширине | Отдельного правила для обычного текста нет |
| Автоматические переносы | Выключены | `!!rule hyphenation` |

Страница по умолчанию A4, поля слева 30 мм, справа 15 мм, сверху и снизу 20 мм. Не придумывай директивы изменения полей или выравнивания, которых нет в документации утилиты.

Шрифты в документ не встраиваются. Если требуемое семейство отсутствует в среде, учитывай подстановку при проверке результата; не называй постраничное оформление проверенным только по исходнику.

## Заголовки

| Параметр | По умолчанию | Правило |
|---|---|---|
| Размер H1–H6 | 14 пт | `!!rule headings h1 size 18` |
| Интервал перед H1 | 18 пт | `!!rule headings h1 spacing before 0` |
| Интервал перед H2–H6 | 8 пт | `!!rule headings h2+ spacing before 12` |
| Интервал после | 4 пт | `!!rule headings h1+ spacing after 6` |
| Верхний регистр | Выключен | `!!rule headings h1 uppercase` |
| Вид отступа | `first_line` | `!!rule headings h1+ indent left` |

`h1` означает только первый уровень; `h2+` — второй и последующие. Вместо показанного уровня можно выбрать H1–H6. Для отступа доступны `first_line` и `left`; верхний регистр можно выключить значением `off`.

Набор `!!rule headings alt_style_1` меняет сразу несколько параметров: H1 — 18 пт и верхний регистр, H2 — 16 пт, отступы заголовков — `left`, интервал после — 10 пт, перед H1 — 0 пт, перед H2–H6 — 15 пт. Используй его только при соответствии требованиям, а не как обязательный признак отчёта.

## Таблицы

| Параметр | По умолчанию | Правило и значения |
|---|---|---|
| Начертание названия | `normal` | `!!rule table title style <normal\|bold\|italic>` |
| Размер названия | Наследуется от текста | `!!rule table title size <целое>` |
| Выравнивание названия | Влево | `!!rule table title align <left\|center\|right>` |
| Интервал перед названием | 0 пт | `!!rule table spacing before <целое>` |
| Интервал после таблицы | 8 пт | `!!rule table spacing after <целое>` |
| Начертание первой строки | `normal` | `!!rule table heading style <normal\|bold\|italic>` |
| Выравнивание первой строки | `center` | `!!rule table heading align <left\|center\|right\|keep>` |
| Размер текста ячеек | 12 пт | `!!rule table text size <целое>` |
| Межстрочный интервал ячеек | 1.25 | `!!rule table text line_spacing <число>` |

`title` относится к названию над таблицей, `heading` — к первой строке ячеек. Вариант `keep` берёт выравнивание первой строки из Markdown-столбцов, как у остальных строк. Без двоеточий в разделителе столбец выравнивается влево.

## Листинги

| Параметр | По умолчанию | Правило и значения |
|---|---|---|
| Начертание названия | `normal` | `!!rule code title style <normal\|bold\|italic>` |
| Размер названия | Наследуется от текста | `!!rule code title size <целое>` |
| Выравнивание названия | По ширине | `!!rule code title align <left\|center\|right>` |
| Интервал перед названием | 0 пт | `!!rule code spacing before <целое>` |
| Интервал после листинга | 8 пт | `!!rule code spacing after <целое>` |
| Шрифт кода | Courier New | `!!rule code text font <название>` |
| Размер кода | 12 пт | `!!rule code text size <целое>` |
| Межстрочный интервал кода | 1 | `!!rule code text line_spacing <число>` |
| Подсветка синтаксиса | Выключена | `!!rule code highlight` |

Строчные вставки кода по умолчанию курсивные: `!!rule backtick_mono italic`. Доступны также `off`, `on`, `outline`. В режимах `on` и `outline` используется тот же шрифт, что задан через `code text font`.

## Рисунки и формулы

| Параметр | По умолчанию | Правило |
|---|---|---|
| Размер подписи рисунка | Наследуется от текста | `!!rule img text size <целое>` |
| Интервал перед рисунком | 0 пт | `!!rule img spacing before <целое>` |
| Интервал после подписи или рисунка без подписи | 8 пт | `!!rule img spacing after <целое>` |
| Шрифт формул | Cambria Math | `!!rule formula font <название>` |
| Интервал перед формулой | 8 пт | `!!rule formula spacing before <целое>` |
| Интервал после формулы | 8 пт | `!!rule formula spacing after <целое>` |

Рисунок и его подпись располагаются по центру. Для формул выбирай математический шрифт с поддержкой OpenType MATH.

Если требование нельзя выразить правилами из справочника, проверь документацию той же поставки md2gost. Если поддерживаемого способа нет, сообщи пользователю о конкретном несоответствии и согласуй доступный вариант. Не выдавай несуществующую директиву за настройку и не меняй исходники утилиты ради оформления отчёта без отдельного поручения.
